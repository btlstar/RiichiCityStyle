# RiichiCityStyle · 一番街本地装扮

麻雀一番街 Windows 客户端的独立本地装扮插件，提供轻量图形管理窗口。从 [Releases](https://github.com/btlstar/RiichiCityStyle/releases/tag/v0.1.2) 下载 Windows x64 便携包，完整解压后运行 `RiichiCityStyle.exe`。

## 使用

1. 正常启动一番街，完成官方资源更新后退出游戏。
2. 打开 RiichiCityStyle，选择包含 `Mahjong-JP.exe` 的 `Game` 目录。
3. 点击「查看状态」，确认资源已适配后点击「安装 / 更新」。
4. 正常启动游戏，在原有角色、造型和装扮界面选择内容。
5. 需要停用时，退出游戏并点击「还原游戏文件」。

本地选择按游戏账号保存；还原资源文件后仍保留选择。安装前会先校验并备份原文件，检测到未知官方更新或热更新时会停止覆盖。请保留窗口显示的备份目录。

本次为管理工具维护更新，继续使用已验证的装扮核心 6。

## 功能范围

支持角色与皮肤、头像、称号、星标、装扮方案及本地装备选择。头像、语音和随机方案的覆盖范围有限。不会改变服务器拥有物、抽取、货币或真实养成进度，也不保证其他玩家视角可见。

进入牌桌后皮肤变成默认造型时，请检查游戏「安全模式」是否包含自己。补丁遵循游戏原有的显示设置。

管理工具直接处理本机客户端资源，不需要运行网络代理。游戏本身仍需正常联网。

## 兼容与恢复

- 仅安装到已适配的客户端资源，未知文件不会被覆盖。
- 自动复用与所选游戏目录匹配的既有恢复记录；不同安装目录使用独立备份。
- 新安装的管理资料保存在 `%LOCALAPPDATA%/RiichiCityStyle`，窗口可打开实际备份目录。
- 自动读取旧版管理配置及匹配的恢复记录，升级无需重新设置游戏目录；已有游戏内装扮选择保留。
- 游戏运行时拒绝安装和还原，不会强制结束游戏进程。
- 分发包不包含游戏资源、原始恢复备份、登录资料或个人配置。

## 源码运行

使用 Python 3.12 安装 `requirements.txt` 后运行 `python gui.py`。构建 Windows x64 便携包时安装 `requirements-build.txt` 后运行 `python package.py`；固定依赖见 `requirements-lock.txt`。
